# RAM Flow

Очистка оперативной памяти Windows в духе Mem Reduct, написанная на C# (.NET 8, WinForms).

## Возможности

- **8 областей очистки**: рабочие наборы процессов, системный файловый кэш, изменённые страницы,
  резервный список (целиком или только низкоприоритетный), кэш реестра, объединение одинаковых
  страниц, сброс буферов дисков. У каждой области есть подсказка.
- **Автоочистка** при загрузке выше порога и/или по таймеру, с паузой между очистками,
  чтобы программа не чистила по кругу.
- **Игровой режим.** Пока на переднем плане полноэкранная игра, автоочистка не срабатывает,
  и игра не подлагивает.
- **Исключения.** Процессы из списка (например `gmod`, `hl2`) не выгружаются из памяти.
- **Значок в трее** показывает загрузку в процентах и меняет цвет: синий, затем оранжевый, затем красный.
- **График** загрузки за последние 3 минуты с отметками очисток и линией порога.
- **Горячая клавиша** (по умолчанию `Ctrl + Shift + F1`). Меняется нажатием сочетания в поле.
- **Автозапуск** через Планировщик заданий: при входе в систему нет окна UAC.
- **`RAMFlow.exe --clean`** очищает память и выходит. Удобно для ярлыка.
- Статистика за всё время. Настройки лежат в `%AppData%\RAMFlow\settings.json`.

## Скачать

Готовые файлы лежат во вкладке **Releases**. Новый релиз собирается автоматически после каждого изменения в `main`.

- `RAMFlow.exe` весит около 200 КБ и требует установленного
  [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0).
- `RAMFlow-portable.exe` работает без установки .NET.

Программа запрашивает права администратора: без них Windows не даёт чистить системные списки памяти.

## Сборка

```
dotnet publish src/RAMFlow/RAMFlow.csproj -c Release -r win-x64 -p:PublishSingleFile=true --self-contained false
```
